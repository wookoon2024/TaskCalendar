## 📌 1. 스마트 플로팅 메모 (바탕화면 포스트잇 & 업무 자료 활용)

| 주요 기능 | 설명 및 활용 팁 |
| :--- | :--- |
| **바탕화면 자유 배치 & 위치 자동 기억** | • 메모를 원하는 위치에 배치하면 **프로그램을 껐다 켜도 그 위치·크기·접힘 상태 그대로 100% 자동 복원**됩니다. |
| **전화번호부 / 이미지 본문 삽입** | • 캡처 도구(Win+Shift+S)로 **전화번호부, 비상 연락망, 업무 매뉴얼 등을 복사(Ctrl+C) 후 메모에 붙여넣기(Ctrl+V)**하면 본문에 깔끔하게 삽입됩니다. |
| **파일 드래그 앤 드롭 자동 첨부** | • 탐색기에서 파일을 메모 창으로 **끌어다 놓기(Drag & Drop)**만 하면 파일이 즉시 자동 첨부됩니다. |
| **[신규] 파일 열기 & 파일 폴더 열기** | • **파일 열기 (실행)** : 첨부파일을 기본 연결 프로그램으로 즉시 실행합니다.<br>• **파일 폴더 열기** : 윈도우 탐색기를 열어 **해당 파일이 저장된 위치를 바로 선택(하이라이트)**해 줍니다. |
| **메모 삭제 시 첨부파일 자동 정리** | • 메모를 삭제하면 연결된 첨부파일도 디스크에서 **안전하게 동반 삭제**되어 불필요한 용량을 차지하지 않습니다. |
| **항상 위 고정(📌) 및 투명도 조절** | • 우상단 핀(📌)을 눌러 다른 창보다 항상 위에 띄우거나, 제목 표시줄 더블클릭으로 접기/펼치기가 가능합니다. |

## ⏰ 2. 놓치지 않는 일정 & 사전 알람

* **사전 알림 설정**: 중요한 회의나 업무 마감 전 **5분 전, 10분 전, 15분 전, 30분 전, 1시간 전** 등 사전 알림을 지정할 수 있습니다.
* **실시간 팝업 알림**: 알림 시간이 되면 화면 우측 하단에 알림 팝업이 표시되며, **[확인]** 또는 **[다시 알림 (5분 뒤)]**을 선택할 수 있습니다.

## ⚙️ 3. 환경설정 & 전역 단축키 (업무 속도 UP)

메인 창 우측 상단의 **[환경설정]** 메뉴에서 설정할 수 있습니다.

```mermaid
graph LR
    A[환경설정] --> B[윈도우 시작 시 자동 실행]
    A --> C[캘린더 표시/숨김 단축키]
    A --> D[빠른 메모 생성 단축키]
    B --> E[부팅 시 자동 실행되어 메모/알림 즉시 대기]
    C --> F[다른 프로그램 작업 중에도 즉시 호출]
    D --> G[전화 통화/급한 메모 시 단축키로 1초 만에 작성]
```

1. **윈도우 시작 시 자동 실행**: PC를 켤 때 자동으로 실행되어 플로팅 메모와 알람이 즉각 대기합니다.
2. **캘린더 표시/숨김 단축키**: 인터넷/문서 작업 중에도 지정한 단축키(예: `Ctrl + Shift + C`)를 누르면 캘린더가 바로 열리고 닫힙니다.
3. **빠른 메모 단축키**: 전화 통화나 긴급 메모가 필요할 때 단축키(예: `Ctrl + Shift + M`) 한 번으로 새 메모 창이 즉시 열립니다.
