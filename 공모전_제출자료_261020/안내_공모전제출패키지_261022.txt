■ 3단계 핵심 시연 프로세스 요약표 (인수인계·업무 확인·법령/AI/연동)
--------------------------------------------------------------------------------
[ 1단계: 인수인계 ]
  • 04_모의데이터_인수인계샘플 폴더를 좌측 업무 분류 트리로 드래그
  • 업무 인수인계 창에서 '모두 덮어쓰기' 선택 → '인수인계 시작'
  • 대안: 탐색기에서 파일/폴더 우클릭 → '바로업무 업무로 등록'

[ 2단계: 업무 확인 ]
  • 물품자산 > 불용품처분계획 클릭 → 본문·첨부파일 2건 확인
  • 연계 일정(2026. 11. 13. 물품심사위원회 개최)·연계 문서·북마크 이동 확인

[ 3단계: 법령·AI·연동 ]
  • 상단 참조 법령 '공유재산 및 물품 관리법 제65조' 클릭
  • '내 업무 문서 내용 (인용 문맥)'·'법령 원문 (전체 조문)' 확인
  • 'AI 법령 대조 분석 시작' → 잘못된 항목 2건 → '선택한 2개 항목만 문서에 반영'
  • '업무 부가기능' → '메모로 문서 생성' → '2026년 하반기 불용품 처분 결과 보고' → '메모 원문으로 생성'
  • 05_온나라_모의전자결재사이트\온나라_모의전자결재사이트.html 실행
  • 결재문서 제목 클릭 → '바로업무로 보내기' 본문 스크랩 / '해당 페이지 메모 등록' (크롬 확장의 '파일 URL 액세스 허용' 필요)
  • 윈도우 탐색기 파일·폴더 우클릭 → '바로업무 업무로 등록'
