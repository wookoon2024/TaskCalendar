## 🌟 구동안내서 기반 4대 핵심 기능 상세 명세

본 솔루션은 전임자 퇴직·전보 시 발생하는 구조적 업무 공백과 자료 유실을 원천 차단하고, 복잡한 인수인계를 당일 1시간 내에 완료하도록 돕는 공직 특화 AI 인수인계 플랫폼입니다.

### 1. 🗂️ 비파괴적 폴더 기반 인수인계 자동 구조화 (업무 연속성 보장)
* **전임자 폴더 원클릭 바통터치:** 전임자의 복잡한 윈도우 폴더를 마우스 드래그 한 번으로 `대분류 > 중분류 > 단위업무` 계층 트리로 1초 만에 자동 구조화합니다.
* **디스크-DB 양방향 실시간 동기화:** 업무 분류가 실제 파일 디렉터리(`work/<그룹>/<분류>/<업무명>.hwpx`)로 관리되어, 윈도우 탐색기에서 파일명을 바꾸거나 파일을 추가해도 프로그램과 실시간 동기화됩니다.
* **포터블 인수인계 팩 내보내기/불러오기:** 업무 본문(HWPX), 첨부파일, 연계 일정, 관련 문서 링크, 실무 메모가 압축 패키지 하나로 온전히 보존되어 후임자에게 완벽하게 전달됩니다.

### 2. 🌐 온나라 전자결재 1초 스크랩 & 브라우저 실무 메모 연동
* **웹 결재문서 우클릭 원클릭 스크랩:** 크롬 확장프로그램(단축키 `Ctrl + Shift + K`)을 통해 온나라 전자결재창에서 마우스 우클릭 한 번으로 기안문 제목, 본문 요약, 결재선 정보를 바로업무의 해당 업무 카드로 즉시 전송합니다.
* **해당 페이지 웹 메모(URL 핀포인트):** 법령 정보, 타 부처 고시, 온나라 결재 화면 위에 포스트잇 형태의 메모를 부착하여 해당 페이지 재방문 시 실무 지침과 유의사항이 자동으로 떠오릅니다.
* **윈도우 탐색기 우클릭 등록:** 탐색기에서 문서를 선택하고 우클릭하면 바로업무의 진행 중인 업무 카드로 즉시 첨부 보관됩니다.

### 3. 🤖 생성형 AI 기반 법령·행정절차 자동 대조 및 표준 공문서 생성
* **국가법령정보 실시간 연동 (DRF API):** 업무 본문에서 인용된 법령(예: 공유재산 및 물품 관리법 제65조)을 자동으로 인식하고, 최신 법령 조문과 업무 내용을 실시간 대조합니다.
* **필수 행정 절차 및 누락 서류 AI 사전 검증:** 불용품 매각, 예산 편성, 일상감사 등 행정 절차 표준을 대조하여 누락된 필수 첨부서류나 잘못된 위임전결 결재선을 사전에 경고하고 수정안을 자동 제시합니다.
* **행정업무운영 편람 준수 표준 인수인계서(HWPX) 자동 생성:** 실무 메모와 수집된 결재문서들을 취합하여 표준 서식(표, 칸, 개조식 어법 준수)을 갖춘 정식 HWPX 인수인계서 초안을 1초 만에 자동 생성합니다.

### 4. 🏛️ 공무원 실무 밀착 올인원 행정 유틸리티
* **대한민국 전 기간 공휴일/대체공휴일 동적 계산 엔진:** 역대 대통령령 및 임시공휴일을 포함한 완전 자동 계산(음력 및 24절기 표기 지원).
* **부서 필드 & 공공기관 맞춤형 엑셀 내보내기:** 업무 추진 실적 및 계획을 공공 감사·보고 규격 엑셀로 원클릭 출력.
* **스마트 플로팅 메모 그룹 (위젯):** 다른 업무 중에도 바탕화면에 항상 떠 있는 독립 메모 그룹, 화면 캡처 및 비상연락망 박제 기능 제공.
* **외부 통신 없는 100% 로컬 무손실 암호화:** Windows DPAPI 기반 로컬 DB 암호화 적용으로 보안 감사와 행정망 보안 지침을 완벽 충족합니다.

## 🚀 3단계 핵심 기능 평가 흐름 (구동안내서 시연 순서와 동일)

```mermaid
flowchart LR
    A["[1단계: 업무 인수인계]<br>폴더 드래그 ➔ 계층 구조화<br>AI 법령 조문 대조 분석"] --> B["[2단계: 일정·메모 연동]<br>심사 일정(11.13) 캘린더 등록<br>바탕화면 플로팅 메모 분리"]
    B --> C["[3단계: 문서·온나라 연계]<br>온나라 결재문서 1초 스크랩<br>HWPX 표준 인수인계서 자동생성"]
```

1. **📁 [1단계: 업무 인수인계 & AI 법령 검토]**
   - 상단 메뉴의 **[업무]** 버튼 클릭 후 `공모전_제출자료_261020/04_모의데이터_인수인계샘플/` 폴더를 화면 좌측 업무 트리로 드래그합니다.
   - [모두 덮어쓰기] → [인수인계 시작] 클릭 시 서무복무·예산회계·현안사업 3개 그룹과 30개 단위업무가 1초 만에 자동 복원됩니다.
   - `1/물품자산/불용품처분계획.hwpx` 클릭 후 상단 **[참조 법령: 공유재산법 제65조]** 배너 클릭 ➔ **[AI 법령 대조 분석]** 실행 시 누락 절차를 자동 감지하고 문서에 즉시 반영합니다.
2. **📅 [2단계: 일정·메모 열린 업무창 입체 연동]**
   - 좌측 상단 [일정등록] 클릭 시 캘린더 11월 13일 날짜에 『물품심사위원회 개최』 일정이 즉시 등록됩니다.
   - 우측 상단 [플로팅 메모] 클릭으로 바탕화면 분리 메모 위젯을 띄우고 실무 비상연락망을 박제합니다.
3. **🌐 [3단계: 문서·연동 전자결재 & 탐색기 연동]**
   - `공모전_제출자료_261020/05_온나라_모의전자결재사이트/온나라_모의전자결재사이트.html`을 브라우저로 엽니다.
   - 결재문서 우클릭 ➔ **[바로업무로 보내기]**를 클릭하면 열려 있는 불용품처분계획 업무 카드로 결재선과 본문이 실시간 누적 스크랩됩니다.
   - 상단 **[업무 부가기능] ➔ [메모로 문서 생성]** 클릭 시 행정 표준 서식(HWPX) 인수인계서가 즉시 생성됩니다.

# 바로업무 (TaskCalendar) 프로그램 일반 안내

**바로업무**는 Windows 데스크톱 환경에서 공무 및 업무 효율을 극대화하는 스마트 개인 일정·메모 관리 솔루션입니다.  
새롭게 추가된 **내장 글꼴(Pretendard) 및 150% 고해상도 글꼴 품질 개선**, **환경설정 UI 가독성 향상**, **캘린더 업무내역 표시 및 처리상태 필터링**, **대한민국 전체 공휴일/대체공휴일 동적 계산 엔진**, **부서 필드 & 커스텀 엑셀 내보내기**, **전용 업무 관리자(Task Manager, 상태별 탭·페이징·인라인 수정·100% 반응형 너비)**, **Chrome 확장 프로그램 웹 연동(사이트별 맞춤 추출 규칙·윈도우 프로토콜 연동)**, **스마트 날짜 계산기(D-Day, 기념일, 법정공휴일 제외 영업일/근무일 산정, 나이/근속기간)**, **음력 및 24절기 자동 표기**, **음력 매년 반복 일정(생일/제사)**, **다채로운 일정 스티커/아이콘**, **우측 기준 스마트 확장 및 화면 밖 넘침 방지**, 스마트 플로팅 메모(바탕화면 자동 복원), 첨부파일(폴더 열기 지원), 사전 알람, 전역 단축키, 무손실 로컬 데이터 암호화 저장을 지원합니다.

## 📸 주요 화면 미리보기

바로업무의 4가지 핵심 기능을 화면으로 확인할 수 있습니다.

### 01. 일정 관리 — 월간 캘린더

한 달 전체를 한눈에 보고, 음력·24절기·공휴일을 자동으로 표시합니다. 하루에 여러 일정이
쌓여도 시간이 함께 보이며, 클릭하면 오른쪽에서 그날의 일정과 메모를 함께 확인할 수 있습니다.

![일정 관리 - 월간 캘린더](docs/new_01_schedule.png)

### 02. 메모 관리 — 바탕화면 플로팅 메모와 그룹

메모를 달력 안이 아닌 **바탕화면 위에 떠 있는 창**으로 관리합니다. 다른 일을 하다 잠시
옮겨두고 쓰는 업무 메모에 가깝습니다. 그룹별로 묶을 수 있고, 그룹 안에서 메모를 완료
처리하거나 모두 닫는 버튼, 창을 늘려두는 고정(pin) 기능도 있습니다. 메모 그룹을 여러 개
만들어 업무용·개인용으로 나누어 둘 수 있습니다.

![메모 관리 - 플로팅 메모 그룹](docs/new_02b_memo_group.png)

### 03. 문서 관리 — 크롬 브라우저에서 바로 등록·연계

문서를 직접 타이핑하는 것만큼, **웹에서 바로 가져올 수 있습니다.** 크롬 확장 프로그램
「바로업무로 보내기」를 설치하면 인터넷 서핑 중이거나 웹 업무 화면에서 텍스트를 드래그한 뒤
**우클릭 한 번**으로 그 내용을 바로업무의 일정 · 업무 · 메모로 즉시 전송할 수 있습니다
(전용 단축키 `Ctrl + Shift + K`).

확장 프로그램 설치는 환경설정 → 📄 문서 탭의 「크롬 확장프로그램 연동」 카드에서 진행합니다.
이 화면이 설치 안내 역할을 함께 하며, `🌐 크롬 브라우저 실행` 버튼으로 크롬 확장 관리자를
열어 주고 `📁 확장프로그램 폴더 열기`로 압축을 푼 폴더를 드래그하면 끝납니다.

![문서 관리 - 크롬 확장프로그램 연동 및 설치 안내](docs/new_03b_chrome.png)

문서 목록에서는 분류·부서·상태별로 정리하고 검색·필터링할 수 있으며, 이 문서를 그대로
업무 항목의 관련 문서로 연결할 수도 있습니다.

![문서 관리 - 문서 목록](docs/new_03_document.png)

### 04. 업무 관리 — 단위업무와 AI 도우미

업무를 분류 트리로 정리하고, 각 업무의 본문을 한글(HWPX) 에디터로 작성합니다.
이 에디터는 **이미지 첨부**와 **HWP 문서 드래그&드롭**을 지원하므로, 공문 서식과 표를
그대로 옮겨 붙여 정식 문서를 빠르게 만들 수 있습니다. 우측에서 첨부파일과 관련 일정·문서를
한 화면에 모아 한 업무에 필요한 모든 자료를 볼 수 있습니다.

또한 본문에서 **AI 업무 도우미**를 함께 쓸 수 있습니다. `대화하기`로 공문서·보고서 서식
문장을 작성하고, `업무 분석기`로 본문에서 관련 법령과 필수 행정 절차를 자동으로 찾아 줍니다.

![업무 관리 - 한글 에디터와 AI 업무 도우미](docs/new_04b_work_ai.png)

업무를 다른 업무와 연결하면 업무 흐름 전체를 편람처럼 활용할 수 있습니다.

![업무 관리 - 단위업무와 인수인계 편람](docs/new_04_work.png)

## ✨ 주요 기능

* **🗂️ 업무 파일·첨부를 폴더(work) 기준으로 관리 [v1.9.98 최신]**:
  * 업무 분류가 **실제 폴더**가 됩니다: `work/<그룹번호>/<분류계층경로>/<제목>.hwpx` (하단 탭=그룹, 분류는 상위 폴더까지 중첩)
  * **본문·첨부가 실제 파일**이라 인수자가 탐색기에서 그대로 열 수 있습니다 (`.hwp/.hwpx`는 내장 에디터, 그 외는 윈도우 기본 프로그램)
  * 첨부는 `work/attach/<그룹>/<분류>/<업무명>/`에 모이고, **탐색기에서 파일·폴더 이름을 바꿔도 바로 반영**
  * 업무 이름 변경·분류 이동·분류 이름 변경·삭제 시 **디스크 폴더도 함께 이동**
  * **동기화 창**(2단계·그룹 탭·분류 중첩 트리): 파일 없음/DB 없음 항목을 정리하고, 이름만 바뀐 문서는 내용 해시로 자동 인식
  * **내보내기**(그룹 폴더 복원 + `work.json` 동봉) / **불러오기**(`work.json` 또는 폴더명 기준)
* **🖼️ 한글 에디터 본문 이미지 드래그&드롭 [v1.9.54]**:
  * 탐색기에서 이미지 파일(`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.webp`, `.svg`)을 한글 본문으로 끌어다 놓으면 커서 위치에 즉시 삽입
  * 이미지 외 비이미지 파일 혼합 드롭 시 안전하게 이미지만 자동 필터링 삽입
* **🎨 다크/블랙 스킨 테마 시인성 & 대화상자 스타일 고도화 [v1.9.54]**:
  * 미저장 확인 등 알림 대화상자(`QMessageBox`)에 다크 모드 스타일이 완벽 연동되어 어두운 화면에서도 선명한 가독성 보장
  * 좌측 업무 분류 트리 및 우측 첨부파일 트리의 호버·선택 배경과 텍스트 대비 최적화
* **🤖 AI 업무 도우미 & 법령 찾기 [v1.9.54]**:
  * **본문 우클릭 AI 도우미**: `[대화하기]`로 공문서·보고서 서식 작성, `[업무 분석기]`로 본문에서 관련 법령과 필수 행정 절차 자동 분석
  * **국가법령정보센터 법령 찾기**: `[법령 찾기]`로 현행·연혁 법령을 검색해 공식 페이지(`law.go.kr`)로 바로 연결
    - 기관 전용 Open API 키 적용으로 개칭이 바뀐 구법령(예: 「개인정보 보호에 관한 법률」)도 검색됩니다
    - `현행 법령만 보기` 필터로 구법령을 한 번에 숨길 수 있습니다
  * **AI 설정 연결 테스트**: 입력 중인 엔드포인트·키·모델로 실제 호출해 성공·실패를 즉시 표시
* **📖 기능 안내 5분류 페이지 [v1.9.54]**:
  * `일정 관리`·`메모 관리`·`문서 관리`·`업무 관리`·`환경설정` 5개 분류로 정리
  * 좌측 목록 또는 `[← 이전] [다음 →]` 버튼으로 분류별 상세 안내를 차례대로 확인
  * 각 분류마다 실제 사용법과 **다른 기능과의 연계 방법** 설명 포함

* **🪟 메모/그룹 화면 밖 넘침 완벽 차단 [v1.9.3]**:
  * **상하좌우 모든 방향 클램핑**: 화면 우측에 붙인 메모/그룹을 펼칠 때 좌측뿐 아니라 하단으로도 새어나가던 문제 수정
  * **작업 영역 기준 통합 보정**: X·Y·폭·높이를 화면 작업 영역(`availableGeometry`) 안으로 한 번에 보정
  * **과도한 크기 자동 축소**: 메모 자체가 화면보다 크면 위치뿐 아니라 크기도 화면에 맞춰 잘림 없이 표시
  * **메모/그룹 동시 적용**: 일반 메모와 그룹 메모 양쪽 펼침/접힘 경로에 동일한 로직 적용
  * **다중 모니터 대응**: 보조 화면(음수 좌표) 경계에서도 동일하게 화면 안에 유지
* **🔤 내장 글꼴(Pretendard) & 150% 고해상도 글꼴 품질 개선 [v1.9.1]**:
  * **Pretendard TTF 글꼴 탑재**: Windows DirectWrite에 최적화된 TrueType 정식 글꼴 적용
  * **고해상도(150% 배율) 렌더링 최적화**: 힌팅 왜곡 방지(`PreferNoHinting`) 및 앤티앨리어싱 개선으로 계단현상 없는 부드러운 벡터 곡선 출력
  * **환경설정 UI 가독성 향상**: 좌측 메뉴 글자 크기를 14px DemiBold로 확대, 콤보박스 텍스트 정렬 및 실시간 미리보기 카드 박스 적용
  * **앱 전체 즉시 반영**: 설정 변경 시 열려 있는 창을 포함해 앱 전체 글꼴/크기가 재시작 없이 즉시 적용
  * **OFL-1.1 라이선스 고지**: 오픈소스 고지에 Pretendard(OFL-1.1) 항목 및 라이선스 전문 탭 추가
* **🪟 창 겹침 순서(Z-order) 개선 [v1.9.0]**:
  * **캘린더 클릭 시 최상위 전환**: 캘린더 창 클릭 시 메모/그룹 창 위로 자연스럽게 올라오도록 개선
  * **캘린더 숨김 시 메모 유지**: 캘린더를 숨겨도 메모/그룹 창이 다른 창에 가려지거나 깜박이지 않도록 임시 최상위 처리
  * **재표시 시 위치 보정**: 캘린더 재표시 직후 사용자가 클릭한 결과를 되돌리지 않도록 타이밍 보정

* **📌 캘린더 업무내역 표시/필터링 및 한국 공휴일 엔진 [v1.8.9]**:
  * **캘린더 업무내역 표시 & 상태 필터링**: 환경설정 캘린더 탭에서 업무내역 표시 여부 및 표시할 처리상태(등록, 진행중 등)를 다중 선택하여 필터링
  * **업무 처리상태 자동 연동**: 업무 관리창에서 특정 상태 삭제 시 환경설정 옵션에서도 자동 삭제 동기화
  * **대한민국 전체 공휴일/대체공휴일 동적 엔진**: 추석, 설날, 대체공휴일, 선거일 등 누락 없는 정밀 자동 계산 및 표기
  * **부서 필드 & 커스텀 엑셀 내보내기**: 업무 기안자 부서 필드 지원 및 원하는 기간/조건의 엑셀 추출 기능
  * **접힘 메모 화면 위치 복원 최적화**: 메모 접힘 상태에서 프로그램 재시작 시 앵커 좌표 밀림 방지

* **📋 전용 업무 관리자(Task Manager) 및 브라우저 연동 [v1.7.0]**:
  * **전용 업무 관리창**: 상단바 [업무] 버튼으로 진입하여 등록된 전체 업무를 효율적으로 관리
  * **상태별 탭 & 페이징 모드**: 전체 / 등록 / 진행 / 완료 탭 및 우측 페이징 셀렉터(전체, 10/20/50개씩, 일별, 주간별, 월별) 지원

| `taskcalendar_storage_diagnostic.log` | 상세 로그. 각 항목 머리에 `[코드 21,51]`처럼 번호 표시 |
| `taskcalendar.db.enc.unreadable.<시각>` / `.bak.unreadable.<시각>` | 읽지 못한 원본 DB 보존본 (빠진 데이터가 들어 있으므로 지우지 말 것) |

요약 예: `2026-10-30 | 10 13 21×2 23×2 25 51 55 61` → 부팅 직후 실행(55), 파일 앞에 알 수 없는 머리말(51)로 해독 실패(21·23), 백업으로 복구(25), 1분 뒤 원본이 정상으로 열림(61) — 보안 프로그램 준비 전 일시적 읽기 실패로 판정.

## 실행 방법

### 소스코드 실행
```powershell
python main.py
```

### 실행 프로그램 (.exe) 직접 빌드
빌드 설정은 루트의 `Calendar.spec` 파일에 있습니다. exe 파일명은 이 spec의 `name=` 값이 결정하므로, 이름을 바꾸려면 spec까지 함께 수정해야 합니다:
```powershell
python -m PyInstaller Calendar.spec --noconfirm --clean
```
결과물: `dist\바로업무.exe`
